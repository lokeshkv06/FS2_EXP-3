# Fitness App – React Router

This project is a simple **React Single Page Application (SPA)** that demonstrates **client-side routing** using **React Router DOM** with a reusable **Navbar** component.

## 🔹 Objective

To implement navigation between multiple pages in a React application using **React Router**.

---

## 🔹 Pages

- Home  
- Workout  
- Diet  

---

## 🔹 Features

- Navigation bar with logo and links
- Client-side routing without page reload
- Reusable Navbar component
- Simple UI using CSS

---

## 🔹 Technologies Used

- React
- React Router DOM
- CSS
